# ふたり家計簿

夫婦が**別財布**で、**現金の支払いも多い**家計を、Excelへの転記なしで記録するための家計簿アプリです。
インストール不要の1ページアプリで、データは**その端末の中だけ**に保存されます（サーバーへの送信は一切ありません）。

**登録はスマホ、分析はスマホとPCの両方**を前提に画面を作り分けています。

- **スマホ**：入力画面はアプリ内蔵のテンキー方式。端末のキーボードが出ないので画面が隠れず、
  金額・支払者・負担・カテゴリ・保存ボタンがすべて1画面に収まり、片手で完結します。
- **PC**：左のサイドナビ＋横に広いレイアウト。ホームのカードが2〜3列に並び、グラフを見比べられます。
  入力画面は左に項目・右にテンキーの2カラムで、数字キー／Backspace／Enter（保存）で手を離さず打てます。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 世帯の支出／収入、共同費の**精算額**、夫婦それぞれの支払額、カテゴリ別、予算の消化、6か月の推移、最近の記録 |
| 入力 | テンキー入力、**レシート撮影からの読み取り**、**メモの貼り付けから一括登録** |
| 一覧 | 月ごとの明細。検索・絞り込み・修正・削除 |
| 設定 | 名前、負担割合、月の区切り（給料日基準も可）、入力の初期値、カテゴリと予算、CSV入出力、バックアップ |

### 入力を速くするための工夫

- **テンキー**：⌫ を長押しすると全部消えます。金額は最大7桁。
- **カテゴリ**：よく使う8個だけを出し、「すべて表示」で残りを開きます。並びは**過去の入力の多い順**に自動で変わります。
- **日付**：既定は今日。`‹` `›` で前日・翌日に動かせるので、数日ぶんのレシートをまとめて打つときに速いです。日付をタップすればカレンダーも出ます。
- **保存したあと**：金額だけ消えて、支払者・負担・カテゴリ・日付は残るので、続けて打てます（お店の名前を残すかは設定で選べます）。
- **取り消し**：保存直後のメッセージにある「取り消す」で、直前の登録を打ち直せます。まとめて登録した分も一括で取り消せます。

### 別財布まわりの考え方

- 1件ごとに「**誰が払ったか**」と「**共同 / 個人**」を持ちます。
- 「共同」の支出だけを集めて、設定した負担割合（既定は 50:50）で割り、
  **どちらがどちらにいくら渡せば公平になるか**をホームに表示します。月ごとに「精算ずみ」の記録も残せます。
- 「個人」の支出は精算の対象外です（それぞれのお小遣い扱い）。

### 現金・レシートまわり

- **レシート読取**：写真を選ぶと端末の中で文字認識（Tesseract.js）を行い、金額・日付・店名の候補を出します。
  タップで選んで入力欄に反映する方式なので、読み取りが外れても数タップで直せます。写真そのものも保存できます。
  - 初回だけ日本語の認識データ（約15MB）をネットから読み込みます。以降は端末にキャッシュされます。
- **まとめて貼付**：スマホのメモやExcelからコピーした行をそのまま貼り付けて一括登録できます。

  ```
  8/12 まいばすけっと 2380 食費 夫 現金
  8/12 ランチ 980 外食 妻
  8/13	ドラッグストア	1,540	日用品
  2026-08-14,電車,420,交通,夫,IC
  ```

  区切りはスペース・タブ・カンマのいずれでも構いません。カテゴリを省いた行は、
  店名のキーワードと**過去の入力の履歴**から自動で推測します（同じ店で2回以上選んだカテゴリを優先）。

## 使い方

`index.html` をブラウザで開くだけで動きます。スマホでは「ホーム画面に追加」するとアプリとして起動でき、
オフラインでも使えます（PWA）。アドレスバーが消えるぶん入力画面も広く使えるので、スマホでは追加を推奨します。

ローカルで確認する場合:

```bash
python -m http.server 8123 --directory C:/work/claude/kakeibo
```

## セキュリティ

公開URLで使う前提のため、次の対策を入れています。

### 1. 外部への通信をゼロにしている

家計データがこの端末から出ることはありません。サーバーもアカウントもなく、送信先が存在しません。
それを技術的にも保証するため、**Content-Security-Policy** で外部との通信をすべて禁止しています。

```
default-src 'none'; script-src 'self'; connect-src 'self' data: blob:;
img-src 'self' data: blob:; style-src 'self' 'unsafe-inline';
worker-src 'self' blob:; base-uri 'none'; form-action 'none'; object-src 'none'
```

- `connect-src 'self' data: blob:` の `data:`／`blob:` は端末内のデータを指す仕組みで、外部の通信先ではありません（レシート画像を文字認識に渡すために必要）。
- `style-src` の `'unsafe-inline'` は、グラフの棒の長さを `style` 属性で指定しているため残しています。
  文字列はすべてHTMLエスケープしてから描画しており、スクリプトの実行は `script-src 'self'` で塞いでいます。
- アクセス解析・広告・フォントCDNなどの第三者サービスは一切使っていません。

### 2. 文字認識ライブラリを自前で配信

以前はレシート読み取りに外部CDN（jsDelivr）からライブラリを読み込んでいましたが、
**CDNが改ざんされると任意のコードを実行されうる**ため、`vendor/` に同梱して自分のサイトから配信するように変えました。
日本語の認識データも同梱しているので、**一度読み込めばオフラインでもレシート読み取りができます**。

### 3. パスコードロック（任意・既定はオフ）

設定タブの「パスコードロック」を有効にすると、この端末に保存された**家計データとレシート写真が暗号化**されます。

| 項目 | 方式 |
|---|---|
| 鍵の作り方 | PBKDF2-SHA256、31万回、ソルト16バイトはランダム |
| 暗号 | AES-GCM 256bit（改ざん検知つき） |
| 鍵の置き場所 | メモリのみ。保存も送信もしない |
| 自動ロック | アプリを離れて既定5分で再ロック（すぐ〜15分／しない から選択可） |
| 失敗時 | 回数に応じて待ち時間が延び、総当たりを遅くする |

スマホを他の人に見られる可能性がある場合に有効です。パスコードは4文字以上ですが、**6桁以上を推奨**します。

> **注意**：パスコードはどこにも保存されないため、忘れると復旧できません。有効にする前にバックアップの書き出しをおすすめします。
> また、書き出したバックアップ（JSON）とCSVは暗号化されないので、置き場所にご注意ください。

### 4. 公開リポジトリについて

GitHub Pages（無料枠）で配信するためリポジトリはpublicですが、**入っているのはアプリのコードだけ**で、
家計データは一切含まれません。データはあなたの端末のブラウザ内にのみ保存されます。

## データの保存場所と持ち出し

| 種類 | 保存先 |
|---|---|
| 明細・設定 | localStorage（`futari-kakeibo-v1`） |
| レシート写真 | IndexedDB（`futari-kakeibo-img`） |

- **CSVで書き出す**：Excelでそのまま開ける形式（UTF-8 BOM付き）で全明細を出力します。
- **CSVを読み込む**：いま使っているExcelの家計簿を取り込めます。列の対応（日付・金額・カテゴリなど）は
  取り込み画面で指定でき、見出しから自動で推測もします。知らないカテゴリや支払方法は自動で追加されます。
- **バックアップを保存／復元**：設定を含む全データのJSON。端末の乗り換えや、夫婦の端末どうしの合流に使います
  （復元時に「置き換え」か「追加」を選べます。写真は含まれません）。

## 夫婦2台で使う場合

このアプリはバックエンドを持たないため、端末どうしの自動同期はありません。運用の選び方は2つです。

1. **1台に集約**（おすすめ）：入力係を決め、もう一方はメモをLINE等で送り「まとめて貼付」でまとめて登録する。
2. **各自の端末で入力**：月末にそれぞれ「バックアップを保存」→ 片方の端末で「追加」で復元して合流する。
   IDが重複しないため、二重登録は起きません。

常時同期が必要になったら、Firebase 等のバックエンドを足す形になります。

## 技術メモ

- 依存ライブラリなし（レシート読取時のみ Tesseract.js を CDN から遅延読み込み）
- `index.html` / `app.css` / `app.js` / `sw.js` / `manifest.json` の静的ファイルのみ
- レイアウトの分岐は幅 900px（サイドナビ／複数カラム／テンキー横置きに切替）と、
  縦 730px 以下の端末向けに入力画面を詰める指定の2つ
- グラフの配色は data-viz リファレンスパレット準拠。系列色は 夫=青 `#2a78d6`、妻=橙 `#eb6834`（ダークは `#3987e5` / `#d95926`）。
  予算の状態表示だけはステータス色（good / warning / critical）を使い、色に加えて必ず文字でも状態を示しています。
- ライト／ダーク両対応。ヘッダ右上の ◐ で「端末の設定にあわせる → ライト → ダーク」を切り替えます。
